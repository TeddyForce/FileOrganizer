# File Organizer

A simple Python program that automatically organizes files into folders based on their file type.

## Features

- Organizes images
- Organizes documents
- Organizes music
- Organizes videos
- Automatically creates folders if they don't exist

## Skills Used

- Python
- Dictionaries
- Loops
- os
- shutil
- File Handling

## How to Run

```bash
python3 main.py
```
