# File Organizer

A simple Python program that automatically organizes files into folders based on their file type.

## Features

- Organizes images
- Organizes documents
- Organizes music
- Organizes videos
- Automatically creates folders if they don't exist

## Skills Used

- Python
- Dictionaries
- Loops
- os
- shutil
- File Handling

## How to Run

```bash
python3 main.py
```
## Example

Before running:

```
dog.png
cat.jpg
homework.pdf
notes.txt
music.mp3
movie.mp4
```

After running:

```
Images/
    dog.png
    cat.jpg

Documents/
    homework.pdf
    notes.txt

Music/
    music.mp3

Videos/
    movie.mp4
```
